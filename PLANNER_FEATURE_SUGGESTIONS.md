# Planner Role – Features for City Betterment

The Planner creates improvement plans to solve city problems. Here are more features you could add:

---

## Current Features (Implemented)
- **Problems to Address** – View AI-identified issues and recommendations
- **Create Improvement Plan** – Propose solutions with area, category, description, priority, timeline
- **My Improvement Plans** – Track plans with status: Draft → Submitted → In Progress → Completed
- **Use for Plan** – One-click to pre-fill form from a problem card

---

## Suggested Extra Features

### 1. **Estimated Impact**
- Add "Expected Impact" when creating a plan (e.g. "Reduce traffic by 25%")
- Show impact vs cost or effort
- Helps prioritize high-impact, low-effort plans

### 2. **Budget / Resource Estimate**
- Optional budget range (e.g. ₹5L–₹10L) or "Low / Medium / High cost"
- Resource type: manpower, equipment, external vendor
- Useful for admin approval workflow

### 3. **Link to Citizen Reports**
- Show citizen complaints that relate to each problem
- "3 citizens reported similar issue" badge
- Planner can reference report IDs in their plan

### 4. **Approval Workflow**
- Submit plan for Admin review
- Admin can Approve / Reject / Request Changes
- Status: Draft → Pending Approval → Approved → In Progress → Completed

### 5. **Implementation Timeline**
- Gantt-style or milestone view
- Phases: Planning → Procurement → Execution → Monitoring
- Target dates per phase

### 6. **Map Integration**
- Pin plan location on the city map
- Show all plans as markers (e.g. by category)
- Overlay with traffic/pollution hotspots

### 7. **Collaboration**
- Add notes or updates to a plan
- Attach documents (concept sketches, feasibility reports)
- Comments thread for Admin–Planner communication

### 8. **Scenario Comparison**
- "Plan A vs Plan B" for the same problem
- Compare impact, cost, timeline
- Side-by-side view

### 9. **Success Metrics**
- Define success criteria (e.g. "Traffic < 55%", "AQI < 100")
- Track before/after metrics after implementation
- Show progress toward targets

### 10. **Templates**
- Save plan as template for similar problems
- "New plan from template" for recurring issues
- Category-wise templates (Traffic, Environment, etc.)

---

## Quick Wins
- Estimated impact field
- Budget/effort dropdown (Low/Medium/High)
- Link to related citizen reports
- Plan templates

## Medium Effort
- Approval workflow
- Implementation timeline view
- Map markers for plans

## Higher Effort
- Scenario comparison
- Success metrics tracking
- Full collaboration (comments, attachments)
